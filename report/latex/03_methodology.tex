\section{Methodology}
\label{sec:Methodology}

Figure~\ref{fig:fintrace_architecture} summarises the preparation and answer paths. Structured financial evidence and full-report prose are searched differently. Source identifiers connect both paths to the original reports; evaluation keys are not runtime evidence.
