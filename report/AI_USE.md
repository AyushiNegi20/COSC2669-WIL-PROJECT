# Account of generative AI assistance

ChatGPT/Codex and Claude were used during this project for concept explanations,
brainstorming, technical comparisons, code generation and debugging, test and
evaluation support, interpretation of failures, presentation preparation,
diagram and document preparation, report drafting and wording revision. AI
agents also authored and assessed some question sets. These are not external
human-panel judgments, and model self-review is not independent verification.

The written report's technical sections, executive summary, architecture,
editing and Ayushi's reflection received substantive AI assistance. The report
does not claim that all wording or implementation was independently written by
students. Members must verify the account of their work and write or approve
their own personal reflections; an agreed role is not proof of a completed task.

The project scope, selection decisions and acceptance of revisions remain the
group's responsibility. Repository checks, retained first responses, source
pages and arithmetic provide evidence for specific claims, not blanket assurance
of correctness. Exposed evaluation questions are treated as regression material.

This records actual use rather than classifying all assistance as permitted
surface-level polishing. The group must reconcile it with the written-report
assessment conditions and complete the accompanying Condition 3 declaration.
Any ambiguity about permitted coding or substantive drafting assistance should
be put to the teaching team, not omitted from disclosure.
